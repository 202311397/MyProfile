## 활동 시기와 진행 상태

2026년 10월 ~ (개인프로젝트), 진행 중

## 활동 목적

나의 전공과 학습 활동을 정리하고 다른 사람에게 보여줄 수 있는 포트폴리오 사이트를 만들고자 했습니다. 기존 Hugo 테마를 수정해 나에게 맞는 사이트로 바꾸고 GitHub Pages에 배포하는 과정도 경험하고자 했습니다.

## 본인 역할과 기여 범위

개인 프로젝트로 진행했으며 Hugo 테마 수정과 페이지 구성 변경, 내용 작성, GitHub 저장소 관리 및 배포 과정까지 직접 진행했습니다.

## 수행 과정과 선택 이유

- **기존 테마 수정**: 반려견 미용실을 주제로 만들어진 기존 테마에서 가격표, FAQ, 위치 안내 등 내 포트폴리오와 관련 없는 내용을 정리했습니다.
- **언어 설정**: 사이트의 기본 언어를 한국어로 변경했습니다.
- **화면 문구 한국어화**: 버튼과 안내 문구("Read more", "Back to blog" 등)를 `i18n/ko.yaml`에서 한국어로 바꿨습니다.
- **활동 페이지 변경**: 기존에는 반려견의 Before/After 사진을 보여주는 형태였지만, 학습 및 프로젝트 활동을 정리할 수 있도록 카드 목록 형태로 화면을 변경했습니다. 테마 원본 파일을 직접 수정하는 대신 별도의 화면 파일을 만들어 적용했습니다.
- **소개 페이지 수정**: 학습 목표와 역량을 보기 쉽게 정리하고 기존 내용을 나의 전공과 관심 분야에 맞게 변경했습니다.
- **내용 작성**: 홈 화면과 소개 페이지에 나의 전공, 학습 목표, 관심 분야 등을 작성하고, Git 명령을 정리한 글을 학습 기록에 올렸습니다.
- **배포**: 제공된 스크립트로 GitHub Actions 배포 설정을 저장소에 추가하고 `main` 브랜치에 push할 때마다 자동으로 빌드·배포되는 것을 확인했습니다.

- **배운 점**: 기존 테마의 파일을 수정하고 새로운 화면을 적용하는 방법을 익혔습니다. 또한 GitHub Actions의 빌드 로그를 확인해 오류가 발생한 파일과 줄 번호를 찾고 수정하는 방법도 배웠습니다.
- **어려웠던 점**: 글 설정을 작성하는 과정에서 YAML 문법 오류가 발생해 빌드가 실패했습니다. Actions 로그에서 오류가 발생한 파일과 줄 번호를 확인하고 수정하면서 문제를 해결했습니다.
- **한계**: Hugo 테마의 전체 구조를 아직 이해하지 못해 일부 화면은 기존 디자인을 그대로 사용하고 있습니다.
